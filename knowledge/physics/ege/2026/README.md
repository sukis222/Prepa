# ЕГЭ по физике: задания 1–26

Темы и формулы по заданиям из [навигатора ФИПИ](https://fipi.ru/navigator-podgotovki/navigator-ege#fi), редакция 2026 года.

В каждой карточке — краткое описание задачи и раздел «Что нужно знать». Название темы ведёт на соответствующую страницу [учебника И. В. Яковлева](../../../library/mathus/README.md). Под формулами раскрыты величины; единицы измерения указаны в скобках. Для обзорных заданий приведены ссылки на нужные разделы книги.

В книге нет отдельных глав об измерениях и планировании эксперимента: для заданий 19–20 оставлены ссылки на навигатор ФИПИ. Если просмотрщик PDF не учитывает `#page=N`, нужную страницу можно ввести вручную; правила нумерации описаны в [разделе книги](../../../library/mathus/README.md).
