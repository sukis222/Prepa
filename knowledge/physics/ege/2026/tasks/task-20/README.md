# Задание 20

Выбор приборов и оборудования для проверки физической гипотезы.

## Что нужно знать

### Исследование зависимости одной величины от другой

По гипотезе определить, какую величину изменяют, какую измеряют и какие условия сохраняют неизменными. Выбрать оборудование, позволяющее изменить нужную величину и провести измерение.

У задания нет универсальной расчётной формулы. В книге Яковлева нет отдельной главы о планировании школьного эксперимента; проверяемое умение описано в [навигаторе ФИПИ](../../sources/fi-5-kvant.pdf#page=3).
