# Задание 14

Анализ процесса по электродинамике или оптике с выбором верных утверждений.

Могут проверяться любые темы раздела «Электродинамика», включая оптику.

## Что нужно знать

### [Электрическое поле](../../../../physics-yakovlev.pdf#page=166)

$\displaystyle \vec E=\frac{\vec F}{q}$

$\vec E$ — напряжённость электрического поля, (Н/Кл, В/м).  
$\vec F$ — сила, действующая на пробный заряд, (Н).  
$q$ — пробный заряд с учётом знака, (Кл).

### [Плоский конденсатор](../../../../physics-yakovlev.pdf#page=188)

$\displaystyle C=\frac{q}{U}=\frac{\varepsilon\varepsilon_0S}{d},\qquad W=\frac{CU^2}{2}$

$C$ — электроёмкость, (Ф).  
$q$ — модуль заряда одной обкладки, (Кл).  
$U$ — напряжение, (В).  
$\varepsilon$ — относительная диэлектрическая проницаемость, (безразмерная).  
$\varepsilon_0$ — электрическая постоянная, (Ф/м).  
$S$ — площадь одной обкладки, (м²).  
$d$ — расстояние между обкладками, (м).  
$W$ — энергия электрического поля, (Дж).
