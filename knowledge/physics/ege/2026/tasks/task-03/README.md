# Задание 3

Расчётная задача на импульс, работу и механическую энергию.

## Что нужно знать

### [Импульс. Закон сохранения импульса](../../../../physics-yakovlev.pdf#page=73)

$\displaystyle \vec p=m\vec v$

$\displaystyle \sum\vec p_{\text{до}}=\sum\vec p_{\text{после}}$

$\vec p$ — импульс тела, (кг·м/с).  
$m$ — масса тела, (кг).  
$\vec v$ — скорость тела, (м/с).  
$\sum\vec p$ — суммарный импульс системы тел, (кг·м/с).

### [Работа силы](../../../../physics-yakovlev.pdf#page=80)

$\displaystyle A=Fs\cos\alpha$

$A$ — работа силы, (Дж).  
$F$ — модуль постоянной силы, (Н).  
$s$ — модуль перемещения, (м).  
$\alpha$ — угол между силой и перемещением, (рад или °).

### [Кинетическая энергия](../../../../physics-yakovlev.pdf#page=82)

$\displaystyle E_{\text{к}}=\frac{mv^2}{2}$

$\displaystyle \Delta E_{\text{к}}=\sum A$

$E_{\text{к}}$ — кинетическая энергия тела, (Дж).  
$m$ — масса тела, (кг).  
$v$ — модуль скорости, (м/с).  
$\Delta E_{\text{к}}$ — изменение кинетической энергии, (Дж).  
$\sum A$ — сумма работ всех сил, (Дж).

### [Потенциальная энергия](../../../../physics-yakovlev.pdf#page=83)

$\displaystyle E_{\text{п}}=mgh$

$\displaystyle E_{\text{упр}}=\frac{kx^2}{2}$

$E_{\text{п}}$ — потенциальная энергия в однородном поле тяжести, (Дж).  
$m$ — масса тела, (кг).  
$g$ — ускорение свободного падения, (м/с²).  
$h$ — высота над выбранным нулевым уровнем, (м).  
$E_{\text{упр}}$ — энергия упругой деформации пружины, (Дж).  
$k$ — жёсткость пружины, (Н/м).  
$x$ — деформация пружины, (м).

### [Изменение и сохранение механической энергии](../../../../physics-yakovlev.pdf#page=85)

$\displaystyle E_{\text{мех}}=E_{\text{к}}+E_{\text{п}}$

$\displaystyle \Delta E_{\text{мех}}=A_{\text{непот}}$

$E_{\text{мех}}$ — механическая энергия, (Дж).  
$E_{\text{к}}$ — кинетическая энергия, (Дж).  
$E_{\text{п}}$ — суммарная потенциальная энергия учитываемых взаимодействий, (Дж).  
$A_{\text{непот}}$ — работа непотенциальных сил, например трения, (Дж).
