# Задание 16

Задача на состав атома и ядра, ядерные превращения или радиоактивный распад.

## Что нужно знать

### [Планетарная модель атома](../../../../physics-yakovlev.pdf#page=433)

Атом состоит из положительно заряженного ядра и электронов; в нейтральном атоме число электронов равно числу протонов в ядре.

$\displaystyle N_e=Z$

$N_e$ — число электронов в нейтральном атоме, (безразмерное).  
$Z$ — порядковый номер элемента, равный числу протонов, (безразмерный).

### [Нуклонная модель ядра](../../../../physics-yakovlev.pdf#page=446)

$\displaystyle {}^{A}_{Z}X,\qquad N_n=A-Z$

$X$ — символ химического элемента.  
$A$ — массовое число, то есть число нуклонов, (безразмерное).  
$Z$ — зарядовое число, то есть число протонов, (безразмерное).  
$N_n$ — число нейтронов, (безразмерное).

### [Альфа- и бета-распад](../../../../physics-yakovlev.pdf#page=449)

$\displaystyle {}^{A}_{Z}X\longrightarrow{}^{A-4}_{Z-2}Y+{}^{4}_{2}\mathrm{He}$

$\displaystyle {}^{A}_{Z}X\longrightarrow{}^{A}_{Z+1}Y+{}^{0}_{-1}e+\bar\nu_e$

$\displaystyle {}^{A}_{Z}X\longrightarrow{}^{A}_{Z-1}Y+{}^{0}_{+1}e+\nu_e$

$X$, $Y$ — исходный и дочерний элементы.  
$A$ — массовое число исходного ядра, (безразмерное).  
$Z$ — зарядовое число исходного ядра, (безразмерное).  
$\mathrm{He}$ — в схеме распада альфа-частица, ядро гелия с массовым числом 4 и зарядовым числом 2.  
$e$ — электрон, бета-частица с массовым числом 0 и зарядовым числом −1.  
$^{0}_{+1}e$ — позитрон, бета-частица с массовым числом 0 и зарядовым числом +1.  
$\bar\nu_e$, $\nu_e$ — электронное антинейтрино и нейтрино; их массовые и зарядовые числа равны нулю.

### [Ядерные реакции](../../../../physics-yakovlev.pdf#page=458)

По известным участникам реакции определяют неизвестную частицу, сохраняя суммарный электрический заряд и суммарное число нуклонов.

### [Закон радиоактивного распада](../../../../physics-yakovlev.pdf#page=451)

$\displaystyle N(t)=N_0\,2^{-t/T},\qquad m(t)=m_0\,2^{-t/T}$

$N(t)$ — число нераспавшихся ядер к моменту $t$, (безразмерное).  
$N_0$ — исходное число радиоактивных ядер, (безразмерное).  
$m(t)$ — масса нераспавшегося радиоактивного изотопа, (кг).  
$m_0$ — исходная масса этого изотопа, (кг).  
$t$ — прошедшее время, (с).  
$T$ — период полураспада, (с).

Определять период полураспада по графику зависимости числа распавшихся частиц от времени.
