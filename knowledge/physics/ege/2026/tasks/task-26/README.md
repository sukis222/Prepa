# Задание 26

Расчётная задача по механике с обоснованием применимости физических законов.

## Что нужно знать

### [Кинематика](../../../../physics-yakovlev.pdf#page=27)

Системы отсчёта, описание движения и его участков; проекции скорости и ускорения. Для движения с постоянным ускорением:

$\displaystyle v_x=v_{0x}+a_xt,\qquad x=x_0+v_{0x}t+\frac{a_xt^2}{2}$

$x$, $x_0$ — текущая и начальная координаты, (м).  
$v_x$, $v_{0x}$ — текущая и начальная проекции скорости, (м/с).  
$a_x$ — проекция ускорения, (м/с²).  
$t$ — время от начала рассматриваемого участка, (с).

### [Динамика](../../../../physics-yakovlev.pdf#page=51)

Законы Ньютона, силы тяжести, упругости и трения; уравнения движения связанных тел.

$\displaystyle \sum\vec F=m\vec a$

$\sum\vec F$ — векторная сумма сил, действующих на рассматриваемое тело, (Н).  
$m$ — масса тела, (кг).  
$\vec a$ — ускорение в выбранной инерциальной системе отсчёта, (м/с²).

### [Законы сохранения в механике](../../../../physics-yakovlev.pdf#page=73)

Сохранение импульса системы при нулевом суммарном импульсе внешних сил; сохранение [механической энергии](../../../../physics-yakovlev.pdf#page=80) при нулевой суммарной работе неконсервативных сил.

$\displaystyle \sum\vec p_{\text{до}}=\sum\vec p_{\text{после}},\qquad E_{\text{к}}+E_{\text{п}}=\mathrm{const}$

$\vec p$ — импульс тела, $\vec p=m\vec v$, (кг·м/с).  
$m$ — масса тела, (кг).  
$\vec v$ — скорость тела, (м/с).  
$E_{\text{к}}$ — кинетическая энергия выбранной системы тел, (Дж).  
$E_{\text{п}}$ — потенциальная энергия взаимодействий, включённых в систему, (Дж).  
Индексы «до» и «после» — два рассматриваемых состояния.

### [Статика](../../../../physics-yakovlev.pdf#page=63)

Равновесие тел, моменты сил и плечи, выбор точки для записи уравнения моментов.

$\displaystyle \sum\vec F=0,\qquad \sum M=0,\qquad |M|=Fl$

$\vec F$ — сила, (Н); $F$ — её модуль.  
$M$ — момент силы относительно выбранной оси с учётом знака, (Н·м).  
$l$ — плечо силы: перпендикулярное расстояние от оси до линии действия силы, (м).
