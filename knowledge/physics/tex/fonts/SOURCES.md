# Локальные шрифты для новых материалов

Эти OTF — производные CM-Super Type 1 Владимира Воловича. Контуры взяты из
`knowledge/physics/yakovlev-1-16/fonts/*.pfb`, метрики и кернинг — из
соседних LH TFM и кодировки T2A. Исходные файлы и их происхождение хранятся
в той папке. Конвертация не меняет исходные PFB/TFM контрольной копии.

Официальный пакет: <https://ctan.org/pkg/cm-super>.

Преобразование выполнено проектным `build_otf.py` с FontTools 4.68.0.
Из корня репозитория:

```powershell
.venv/Scripts/python.exe knowledge/physics/tex/fonts/build_otf.py
```

Кубические контуры Type 1 переносятся в CFF; координаты и метрики
масштабируются к 10 000 единицам на em. Добавлены Unicode cmap,
GPOS-кернинг и стандартные лигатуры T2A. Отдельный Unicode-адаптер TeX
не требуется, поэтому работают русские переносы Babel. Производным
шрифтам даны новые внутренние имена `CM Super Replica …` / `CMReplica-…`.

Лицензия CM-Super: GPL с разрешением на встраивание шрифтов в документы.
См. `COPYING`, `CM-SUPER-README` и исходные уведомления в PFB. Код
конвертации и исходные контуры остаются в репозитории; сборка материалов
не требует ни Python, ни FontTools, поскольку готовые OTF включены.
