# Общий шаблон учебных материалов

Оформление задаёт `physics-textbook.sty`. В файле материала подключить пакет
и писать содержание; не копировать туда преамбулу и настройки размеров.

```tex
\documentclass[12pt,a4paper]{article}
\usepackage{physics-textbook}
\begin{document}
\BookParagraph{0}{Название параграфа}
Текст.
\BookSubsection{0.1}{Название раздела}
Текст и формулы.
\end{document}
```

Полный небольшой пример — `minimal.tex`. Исходник работает из любой папки
проекта при наличии путей поиска в рецепте сборки.

## Сборка

Компилятор — Tectonic, движок XeTeX. К стандартным аргументам проекта
нужны пути поиска `knowledge/physics/tex` и `knowledge/physics/tex/fonts`.
В `.vscode/settings.json` они указываются абсолютными путями, потому что
LaTeX Workshop запускает компилятор из папки документа. Рецепт проекта —
единственный источник команды сборки; параметры в отдельных материалах
не переопределяются.

Python-зависимость превью установлена в проектной `.venv` и объявлена
в дополнительном наборе `textbook` (`pip install -e ".[textbook]"`).
Из корня проекта сборку и подготовку превью всех страниц выполняет:

```powershell
.venv/Scripts/python.exe -X utf8 scripts/build_textbook.py knowledge/physics/themes/00-fundamentals/fundamentals.tex
```

PDF и SyncTeX создаются рядом с основным TeX-файлом, превью —
в `tmp/textbook-previews/`. Скрипт проверяет свежесть результатов
и переполнения строк; содержательную и визуальную проверку выполняет агент.
Нулевой параграф служит примером разделения: `fundamentals.tex`
подключает пакет, `content.tex` содержит текст, `vapour-diagram.tex` — схему.

## Что фиксировано в коде

Страница A4, основной шрифт CM-Super 12 pt, интерлиньяж 14,5 pt,
абзацный отступ 17,625 pt. Левое поле — 43,654 bp, ширина текста —
510,236 bp. Заголовки — CM-Super Bold 17,28 и 14,4 pt.
Формулы набираются средствами `amsmath`, математические шрифты — Computer
Modern. Русские переносы автоматические, без ручной разметки каждого слова.

Это общий стиль новых материалов, а не механизм воспроизведения конкретных
страниц: ручные сдвиги из контрольной реконструкции сюда не перенесены.

## Рисунки

Все новые схемы создаются в TikZ. Общие стили:

```tex
\begin{tikzpicture}[book diagram]
  \draw[book body] (0,0) rectangle (1,.5);
  \draw[book force] (1,.25)--(2,.25) node[above] {$\vec F$};
  \draw[book displacement] (0,-.5)--(3,-.5)
    node[midway,below] {$\vec s$};
\end{tikzpicture}
```

`book diagram` задаёт линии 0,5 bp и подписи 10 pt. `book force` —
красная стрелка, `book displacement` — синяя, `book body` — серое тело,
`book projection` — пунктирная вспомогательная линия. Геометрию, масштаб
и размещение подписей агент строит по физической модели и проверяет в PDF.

Для графиков задач используются `task graph`, `task axis`, `task curve`,
`task projection`, `task grid`, `task tick` из того же пакета. Основная линия
толще осей, сетка светлее, координатные проекции имеют фиксированный мелкий
штрих в физических единицах pt. Координаты, форма зависимости, масштаб,
направления и подписи сохраняют данные источника; дефекты растровых линий
восстанавливаются до читаемой геометрии. Каталог типов на согласование —
`output/fipi-physics/graph-style-samples.tex`; массовое приведение остальных
графиков выполняется после выбора пользователем этого образца.

Для заданий на соответствие: `\TaskMatchingColumns[ширина слева]`
`{заголовок слева}{список слева}{заголовок справа}{список справа}`.
Ширина слева по умолчанию `.53\linewidth`, справа — остаток от `.96\linewidth`.
Заголовки обычным регистром, тем же шрифтом и кеглем, что и списки, с жирным
начертанием; интервалы задаёт
макрос. `\TaskChangeTable{первая величина}{вторая величина}` строит пустую
таблицу изменений на полную ширину условия с переносом текста в ячейках.

Числовые таблицы данных (время, заряд, ток, результаты измерений) имеют
полную внешнюю рамку и разделители каждой строки и столбца. Значения и
единицы сохраняются. Это правило относится к таблицам данных; вложенные
`tabular`, служащие компоновкой рисунков или ячеек периодической системы,
оформляются по смысловой структуре изображения.
Шаблон обеспечивает одинаковое оформление, но сам по себе не проверяет
содержательную правильность рисунка.

Шрифты локальные, установка в Windows не требуется. Происхождение и
воспроизводимое преобразование описаны в `fonts/SOURCES.md`.
