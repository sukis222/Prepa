# И. В. Яковлев. Физика

[Открыть учебник](../../physics/physics-yakovlev.pdf).

Копия предоставленного пользователем `D:\Downloads\book.pdf`: 490 страниц, встроенное оглавление. Файл сохранён без изменений. Автор и название подтверждены титульной страницей и метаданными PDF; метаданные указывают 2013 год.

Из карточек заданий ссылки ведут на физические страницы PDF через `#page=N`. Номер страницы файла может отличаться от печатного номера. Поддержка перехода зависит от просмотрщика: если открылась первая страница, введите номер из `#page=N` в поле страницы PDF.

Книга служит источником объяснений и рисунков по темам. Нумерация и состав заданий в базе определяются навигатором ФИПИ 2026 года.
