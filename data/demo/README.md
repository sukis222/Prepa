# Демонстрационные данные

`content_agents.json` содержит вымышленных учеников и авторский пример по равномерному
прямолинейному движению: context, theory, assignments, review. Это синтетические
материалы, не официальный банк ФИПИ. Реальные профили и закрытая библиотека не используются.

review в файле — записанный ReviewReport без digest и поля approved. Offline-клиент
воспроизводит ответы через public async API, ReviewerAgent вычисляет digest и создаёт
ReviewResult. Успех такого прогона подтверждает путь интеграции, не качество живой LLM.

Из корня репозитория после установки `pip install -e '.[dev]'`:

```bash
python examples/content_agents.py --output-dir output/content-demo
```

Создаются `teacher.json`, `student-a.json`, `student-b.json`. PDF, TeX-компиляция, сеть
и секреты не требуются. Ученический вариант создаётся LessonPackage.for_student(id):
только своё ДЗ, условия общей практики, теория и используемые ссылки. Решения примеров
теории сохраняются намеренно; ответы/решения упражнений, чужое ДЗ и сырой content
библиотеки исключены.

Контрольные ответы: пример theory-motion — 200 м; lesson-1 — 10 м/с; lesson-2 — 300 м;
homework-a-1 — 450 м; homework-b-1 — 35/3 м/с (≈11,67 м/с). Ученик A тренирует перевод
км/ч в СИ, ученик B — среднюю путевую скорость при разных временах участков. Практика
занимает 10 минут, ДЗ A — 8, ДЗ B — 12 при отдельных лимитах 20 минут.

После изменения fixture заново проверить контракт/числа, тесты и demo. Не вычислять
digest вручную: в файле хранится исходный ответ проверяющего, привязку выполняет код.
