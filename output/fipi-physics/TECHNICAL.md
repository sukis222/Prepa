# Работа с подборками

Здесь собраны инструкции по редактированию, сборке и проверке материалов.
Пользовательский каталог находится в [README.md](README.md).

Выбор корня версии репетитора проверен на коде установленного LaTeX Workshop:
при старом корне №4 все двадцать файлов выбирают свой `tutor-NN.tex` и PDF.
Официальное описание механизма: [Root file discovery](https://github.com/James-Yu/LaTeX-Workshop/wiki/Compile#the-root-file).
Если в редакторе осталась прежняя вкладка PDF, откройте нужные «Решения»
из каталога и заново выполните сборку. Сам интерфейс редактора инструменту
недоступен; проверены код выбора корня и командная сборка.

## Редактирование

Задачи редактируются в одном постоянном `task-NN.tex`. Файл `tutor-NN.tex`
подключает его, показывает решения и кликабельные ссылки на источники.
Правки задач автоматически попадают в обе версии. Для просмотра комплекта
репетитора используйте ссылку «Решения» в каталоге.

В основном файле решения хранятся в тех же блоках и скрыты по умолчанию:
замените `\ShowSolutionsfalse` на `\ShowSolutionstrue`, чтобы показать их.
Новые задачи можно дописывать блоками `\BankTask{ID}{условие}{решение}`
перед `\end{document}`; нумерация автоматическая.

Формулы и схемы редактируемые LaTeX/TikZ; настоящие фотографии приборов
вставлены из оригиналов. Источники и ID сохранены в комментариях TeX,
служебные данные — в `_run/part1-20/`.

Привязка 400 задач ФИПИ по содержанию — к официальной спецификации 2027.
У каждой задачи есть краткое решение GPT с явной пометкой;
условия, формулы, решения и исходные рисунки прошли независимую сверку.

## Экспорт и сборка

Вторая часть (№21–26) хранится в тех же постоянных `task-NN.tex` и
`tutor-NN.tex`. Проверенный снимок, отбор и протоколы — `_run/part2-30/`.
Старый снимок содержит условия ФИПИ и решения с пометкой «Решение от GPT».
Текущие №21–26 содержат карточки «Решу ЕГЭ» с их опубликованными
решениями. Карты соответствий и замен хранятся в
`.scratch/task26-quality/source-map.json` и `.scratch/part2-source-repair/`.
Для повторного экспорта старого снимка используйте отдельную папку.
В №24 оставлено 29 разных условий: близкие числовые варианты исключены.

Повторный экспорт второй части без модели и сети:

```powershell
.venv/Scripts/python.exe -X utf8 -m prepa.task_harvester export-tex --bundle output/fipi-physics/_run/part2-30/reviewed.json --output tmp/part2-30-replay
```

Временные PDF и постраничные превью проверки второй части находятся
в `tmp/part2-30-check/`; в каталог опубликованы только редактируемые TeX.
Студенческий и репетиторский файлы указывают собственный корень сборки.
Командная сборка использует рецепт `.vscode/settings.json`.
Открытие внутри LaTeX Workshop не проверено: инструмент управления
редактором завершился ошибкой Windows sandbox.

Повторный экспорт проверенного снимка без модели и сети из корня проекта:

```powershell
.venv/Scripts/python.exe -X utf8 -m prepa.task_harvester export-tex --bundle output/fipi-physics/_run/part1-20/reviewed.json --output output/fipi-physics
```

Команда дописывает новые ID, сохраняет существующие блоки, ручные правки
и переключатель решений. Повтор с тем же снимком побайтово идентичен.
Общий стиль — `knowledge/physics/tex/physics-textbook.sty`; рецепт компиляции —
`.vscode/settings.json`.

LaTeX Workshop должен учитывать magic comments (`latex-workshop.latex.enableMagicComments: true`).
Каждый `tutor-NN.tex` указывает самого себя в `% !TEX root = tutor-NN.tex`,
чтобы при сборке открытой версии репетитора не выбирать посторонний основной файл.

## Оформление и проверки

[Образцы единого оформления графиков на согласование](graph-style-samples.tex).
Показанные пользователем графики №8 и оформление соответствия исправлены
в тех же постоянных файлах. Каталог задаёт стиль линий и проекций;
распространение этого стиля на остальные графики ожидает согласования.
Обновлённые списки и таблицы соответствия — в №6, 10, 15, 17;
заголовки набраны тем же шрифтом и кеглем, что и списки, с жирным начертанием.
В трёх числовых таблицах №9 и №13 добавлена полная сетка ячеек.
Единые параметры находятся в `knowledge/physics/tex/physics-textbook.sty`.
Проверка правки оформления — `_run/part1-20/layout-review.json`.

Исходная выдача из 400 задач: обе редакции каждого файла собраны тем же
рецептом Tectonic, просмотрены все 317 страниц. Этот протокол фиксирует
версию до последующей правки оформления. Новые PDF в папку результата
не публиковались. Открытие внутри VS Code проверить не удалось:
инструмент доступа к редактору завершился с ошибкой Windows sandbox.
Протокол — `_run/part1-20/verification.json`.
