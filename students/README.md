# Карточки учеников

Для каждого ученика создайте папку `students/<student-id>/` и скопируйте в неё два шаблона.

- [context.md](_template/context.md) — сведения об ученике в свободной форме. Summarizer дописывает сюда до 200 слов по каждому занятию.
- [README.md](_template/README.md) — дерево тем со статусами «Не пройдено», «В процессе» или «Пройдено» и список решённых задач со ссылками на задачи или подборки.

Карточки учеников хранятся локально. Шаблоны доступны в Git.
