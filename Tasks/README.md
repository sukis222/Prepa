## Как отмечаем готовность

`[ ]` — предстоит сделать; `[x]` — результат получен и проверен. Созданный файл или установленный скилл сами по себе не закрывают задачу качества.

Для готового материала проверены соответствие заданию и теме, корректность формул и внешний вид PDF. Для подборки занятия выпускаются два PDF: задачи ученику и решения репетитору. Опубликованные решения сохраняются без дополнений; при их отсутствии готовятся краткие проверенные решения GPT с пометкой.

Этот файл — общий план. Технические шаги, проверки и история конкретной реализации остаются в [`.scratch`](../.scratch/) по [правилам трекера](../docs/agents/issue-tracker.md). Текущая работа над образцом: [TeX и скилл](../.scratch/tex-reference/issues/01-replica-skill.md).
