# Prepa

Prepa — помощник преподавателя и ученика по физике. В Telegram преподаватель готовит занятия и проверочные, а ученик может отправить фото домашней работы или попросить подсказку к задаче.

[Каталог теории, задач и решений](knowledge/README.md)

## Как устроен проект

Telegram передаёт текст, фотографии и файлы оркестратору. Оркестратор определяет, чего хочет пользователь, уточняет недостающие сведения, формирует задания для нужных агентов и возвращает ответы в Telegram.

1. **[Orchestrator](src/prepa/agents/orchestrator/README.md)** — единая точка входа для всех действий. Разбирает запрос, выбирает агента и передаёт ему только данные, нужные для конкретной операции.
2. **[Checker](src/prepa/agents/homework_checker/README.md)** — восстанавливает и записывает решение ученика по фотографии. Проверяет ход решения, формулы и ответ.
3. **[Task Harvester](src/prepa/agents/task_harvester/README.md)** — подбирает нужное количество задач из локального каталога по темам или номерам ЕГЭ. К подборке может добавить теорию по этим темам.
4. **[Assessment Builder](src/prepa/agents/assessment_builder/README.md)** — составляет проверочную по пройденным темам. Учитывает статусы тем и список уже решённых задач.
5. **[Helper](src/prepa/agents/hint_coach/README.md)** — по условию задачи и попытке ученика даёт одну наводку для следующего самостоятельного шага. Решение и ответ остаются скрытыми.
6. **[Summarizer](src/prepa/agents/summarizer/README.md)** — составляет по транскрипту резюме занятия объёмом до 200 слов. Резюме дополняет контекст ученика в `context.md`.

## Материалы и контекст

- [База знаний](knowledge/README.md) содержит теорию, подборки по номерам ЕГЭ и по темам, условия и решения.
- [Карточки учеников](students/README.md) хранятся локально в `students/<student-id>/`. В `context.md` ведётся свободный текст, а в `README.md` — дерево тем со статусами и список решённых задач.
- [Транскрипты занятий](transcripts/README.md) хранятся локально в `transcripts/<student-id>/`.

## Состояние реализации

Добавлены заготовки шести ролей и маршрутизатор для уже разобранных запросов. Разбор свободного текста и подключение новой маршрутизации к Telegram предстоит реализовать. Текущий бот запускается по [существующей инструкции](docs/telegram-bot.md).
