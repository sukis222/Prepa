# Общие инструменты

Чтение профилей и истории учеников, поиск учебных материалов, разрешённые вычисления, загрузка материалов и сохранение утверждённых результатов. Это обычные программные операции, доступные агентам через ограниченные функции. Доступ к данным проверяется серверным кодом.

Отдельная папка services пока не требуется. При росте кода обычную логику приложения можно будет вынести из инструментов.
