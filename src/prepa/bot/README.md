# Telegram-бот

`app.py` — транспорт aiogram 3, `settings.py` — настройки окружения,
`service.py` — диалог и интерфейс будущего оркестратора. Запуск: `python -m prepa.bot`
или `prepa-bot`. Используется long polling, только личные чаты и разрешённые ID.

Бот вызывает оркестратора напрямую внутри одного Python-приложения. Для первой версии используем long polling: приложение само получает сообщения от Telegram, отдельный веб-сервер не нужен. Код агентов не зависит от Telegram.

Состояние диалога связывается с Telegram-пользователем, выбранными учениками и идентификатором подготовки. Реплика «замени вторую задачу» должна относиться к конкретному документу и его версии. Токен берётся из TELEGRAM_BOT_TOKEN.

Работают добавление и выбор своих учеников, темы, объём занятия и ДЗ, пожелания,
подтверждение, правки, отмена, статус и история. Ученики, запросы и черновики
сохраняются в PostgreSQL и восстанавливаются после перезапуска.
Описание: [docs/telegram-bot.md](../../../docs/telegram-bot.md).

`/homework` и загрузка файлов явно сообщают, что проверка ДЗ ещё не подключена.
