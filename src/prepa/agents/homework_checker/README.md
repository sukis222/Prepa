# Checker

Checker восстанавливает записанное учеником решение по фотографии, соотносит его с исходной задачей и проверяет рассуждения, формулы, единицы измерения и ответ. По каждой задаче он возвращает результат проверки и поясняет найденные ошибки.

Фотографии и условия задач поступают от Orchestrator. Результат проверки возвращается через него же.
