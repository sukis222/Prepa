# Проверка выполненного ДЗ ученика

Получает исходное ДЗ, решение ученика и его профиль. Проверяет ход рассуждений, формулы, единицы измерения и ответ. Возвращает результат по каждому заданию, объяснение ошибок и предложение обновления базы знаний ученика.

Отличается от reviewer: тот проверяет подготовленные материалы до выдачи, этот агент — работу ученика после выполнения. При неразборчивом или неполном решении просит уточнение, не приписывает ученику ошибки по догадке. Обновление профиля происходит после подтверждения преподавателем.

Статус: место для будущей реализации. Здесь будут код агента и инструкции в prompt.md.
