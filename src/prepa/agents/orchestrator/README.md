# Orchestrator

Orchestrator принимает запросы из Telegram, определяет цель и разбивает запрос на действия. Для каждого действия он передаёт нужные материалы и контекст ученика соответствующему агенту. Ответы возвращаются в Telegram через Orchestrator.

| Действие | Исполнитель |
|---|---|
| Проверить решение домашней задачи по фотографии | [Checker](../homework_checker/README.md) |
| Подобрать задачи из локального каталога | [Task Harvester](../task_harvester/README.md) |
| Составить проверочную по пройденным темам | [Assessment Builder](../assessment_builder/README.md) |
| Дать наводку по текущей задаче | [Helper](../hint_coach/README.md) |
| Дополнить контекст ученика по транскрипту | [Summarizer](../summarizer/README.md) |

[Маршрутизатор](router.py) принимает уже определённое действие и передаёт запрос подключённому обработчику. Разбор свободного текста и подключение к Telegram предстоит реализовать.
