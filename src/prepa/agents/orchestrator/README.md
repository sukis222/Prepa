# Оркестратор-собеседник

Единый агент для диалога с преподавателем и управления подготовкой.

1. Получает запрос и читает профиль ученика через общие инструменты.
2. Обсуждает темы, цели, уровень объяснения и объём практики.
3. Фиксирует подтверждение преподавателя и запускает составителей теории и заданий с ДЗ.
4. Передаёт материалы проверяющему, направляет замечания нужному агенту.
5. Передаёт проверенный комплект модулю documents для сборки LaTeX в PDF.
6. Возвращает документ боту для отправки преподавателю. После правок обновляет нужные материалы, повторяет проверку и сборку новой версии.

Порядок этапов, состояние согласования и предел повторов задаются кодом. Отдельных агентов для собеседования, годового планирования и расписания урока нет.

Статус: место для будущей реализации. Здесь будут код агента и инструкции в `prompt.md`.
