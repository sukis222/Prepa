# Задания на урок и домашнее задание

Подбирает практические задания на урок и индивидуальное ДЗ в рамках одного агента. Учитывает согласованные темы, подготовленную теорию, уровень и ошибки ученика. Возвращает условия, ответы, решения и источники. После урока может уточнить ДЗ по фактическим результатам.

Статус: место для будущей реализации. Здесь будут код агента и его инструкции в `prompt.md`.
