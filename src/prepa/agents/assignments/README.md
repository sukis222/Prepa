# Составление заданий на урок и ДЗ

Составляет практические задания на урок и индивидуальное ДЗ в рамках одного агента. Учитывает согласованные темы, подготовленную теорию, уровень и ошибки ученика. Возвращает условия, ответы и решения. После урока может уточнить ДЗ по фактическим результатам. Созданные задания передаются reviewer для проверки до выдачи ученику.

Статус: место для будущей реализации. Здесь будут код агента и инструкции в prompt.md.
