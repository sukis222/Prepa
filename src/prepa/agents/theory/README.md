# Составление теории

По согласованным темам и профилю ученика подготавливает объяснения, формулы с условиями применения и разобранные примеры. Использует инструмент поиска материалов и сохраняет ссылки на источники.

Статус: место для будущей реализации. Здесь будут код агента и его инструкции в `prompt.md`.
