# Проверка материалов

Проверяет теорию, задания и ДЗ: корректность физики, единиц измерения, ответов, соответствие темам и уровню, наличие источников. Возвращает замечания конкретному автору материала. Не заменяет предметную проверку преподавателем.

Статус: место для будущей реализации. Здесь будут код агента и его инструкции в `prompt.md`.
