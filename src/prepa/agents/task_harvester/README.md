# Task Harvester

Task Harvester подбирает нужное количество задач из локального каталога. Orchestrator передаёт темы или номера заданий ЕГЭ, количество и другие критерии из запроса пользователя.

- Для подбора по темам используются коды и названия из раздела «Задачи по темам» в [каталоге](../../../../knowledge/README.md#задачи-по-темам) и файлы в [output/topics/](../../../../output/topics/).
- Для подбора по номерам ЕГЭ используется раздел [«Задания ЕГЭ»](../../../../knowledge/README.md#задания-егэ) и файлы в [output/fipi-physics/](../../../../output/fipi-physics/).

Подборка содержит отобранные задачи. При наличии материалов Task Harvester может добавить ссылки на теорию по теме и решения. Если подходящих задач меньше запрошенного, он сообщает найденное количество и темы или номера, по которым есть нехватка.
