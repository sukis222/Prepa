# Summarizer

Orchestrator передаёт [транскрипт занятия](../../../../transcripts/README.md) из `transcripts/<student-id>/`. Summarizer выделяет важные для дальнейшей работы сведения и составляет запись объёмом не более 200 слов на занятие. Он добавляет её свободным текстом в `students/<student-id>/context.md` после предыдущих записей.

Связь с папкой транскриптов и запись в Markdown предстоит подключить. Существующая [реализация](agent.py) обслуживает прежний сценарий.
