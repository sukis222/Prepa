# Assessment Builder

Orchestrator передаёт идентификатор ученика и параметры проверочной. Assessment Builder читает из `students/<student-id>/README.md` статусы тем и ссылки на решённые задачи. Он собирает проверочную по темам со статусом «пройден» и учитывает решённые задачи при подборе из [локального каталога](../../../../knowledge/README.md#задачи-по-темам).

В ответе указываются темы и подобранные задачи. Если сведений о пройденных темах недостаточно, Assessment Builder передаёт запрос на уточнение через Orchestrator.
