# Назначение папки

Общие форматы данных: StudentProfile, LessonBrief (согласованные темы и ограничения), Theory, Assignment, Homework, ReviewResult и LessonPackage. Форматы предстоит согласовать перед реализацией.

Нужно предусмотреть идентификатор подготовки, версию комплекта и результат сборки документа: путь к PDF или ошибку. Форматы остаются независимыми от Telegram; текст и формулы передаются модулю documents для оформления.

HomeworkSubmission — решение ученика с идентификаторами ученика и выданного ДЗ. HomeworkCheckResult — результаты проверки по заданиям, ошибки, объяснения и предлагаемые изменения профиля.
