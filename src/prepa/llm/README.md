# Общий клиент OpenRouter

`OpenRouterLLM` реализует `StructuredLLM`: JSON schema, ограниченные время/токены,
безопасные ошибки и явная бесплатная модель из окружения. Ключ не хранится в коде.
Реальная подготовка вызывает проверку каталога до передачи профилей учеников.
См. [настройку, кандидатов моделей и ограничения](../../../docs/openrouter.md).
