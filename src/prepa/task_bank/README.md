# Поиск задач по теме

Модуль находит экзаменационные задачи по физике в [открытом банке ФИПИ](https://ege.fipi.ru/bank/)
(ЕГЭ — ege.fipi.ru, ОГЭ — oge.fipi.ru) и выдаёт их текстом. Собственного банка задач у проекта
нет, поэтому ФИПИ — единственный источник условий. Модель здесь не вызывается: поиск — обычная
программная операция, как чтение базы знаний ученика.

## Что выдаёт

`BankTask` — одна задача в том виде, в каком её публикует банк:

- `statement` — условие простым текстом. Формулы из MathML переведены в LaTeX между `$`, рисунки
  заменены метками `[рисунок N]`;
- `images` — абсолютные ссылки на рисунки в том же порядке;
- `options` — варианты ответа для задач с выбором, `matching_keys` — буквы для задач на
  соответствие, `answer_unit` — единица ответа, если банк её показывает;
- `kes` — темы кодификатора (КЭС), `answer_kind` — тип ответа, `url` — прямая ссылка на задачу.

**Ответов и решений нет.** Банк проверяет ответ на своём сервере и не показывает его. Решения
должен составить агент заданий, а проверить — reviewer и преподаватель.

**У большинства задач есть рисунок.** В выборках по механике рисунок есть примерно у 80% задач.
Текстовая модель такую задачу не решит. Для бота рисунки отправляются отдельными картинками,
для LaTeX их нужно скачивать. `with_images=False` оставляет только задачи без рисунков.

## Использование

```python
from prepa.task_bank import FipiClient, TaskSearch, format_result, to_material

async with FipiClient() as client:
    search = TaskSearch(client)
    catalog = await search.topics("ege")  # все темы КЭС с кодами
    result = await search.search("ege", ["1.1.5"], limit=5, exclude_ids=["6EC247"])
    print(format_result(result))  # текст для преподавателя
    materials = [to_material(task, ["Равномерное движение"]) for task in result.tasks]
```

`topics` в `search` — коды КЭС (`1.1.5`) или названия тем. Название сопоставляется с заголовками
КЭС по уровням: точное совпадение, все слова целиком, все основы слов. Частичных совпадений нет:
по запросу «квантовая гравитация» поиск сообщит об ошибке `UnknownTopicError`, а не вернёт всю
квантовую физику. Обиходные формулировки преподавателя («период полураспада») часто не совпадают
с заголовками КЭС. Поэтому оркестратору лучше получить список `topics(exam)` и выбрать коды самому,
а сопоставление по названию оставить для консоли.

Родительский код включает дочерние: `1.1` — вся кинематика. Коды ОГЭ и ЕГЭ различаются, например
равномерное прямолинейное движение — `1.3` в ОГЭ и `1.1.5` в ЕГЭ.

Без `seed` задачи идут в порядке банка: результат воспроизводим. С `seed` страницы и задачи
перемешиваются, чтобы повторные занятия по теме не начинались с одних и тех же задач.
`exclude_ids` убирает уже выданные ученику задачи. Их список будет приходить из истории ученика.

`to_material` превращает задачу в общий `Material` для агентов теории и заданий. Темы передаёт
вызывающий код: это темы из `LessonBrief`, по которым шёл поиск, а не заголовки КЭС.

## Консоль

```bash
python -m prepa.task_bank --exam ege --topic 1.1.5 --limit 5
python -m prepa.task_bank --exam oge --topic "закон архимеда" --kind multiple_choice
python -m prepa.task_bank --exam ege --topic кинематика --no-images --seed 7
python -m prepa.task_bank --exam oge --list-topics движение
python -m prepa.task_bank --exam ege --topic 1.1.5 --json
```

## Устройство

| Файл | Назначение |
|---|---|
| `models.py` | `BankTask`, `KesTopic`, `SearchResult`, `AnswerKind` |
| `search.py` | Сопоставление тем, фильтры, страницы, случайная выборка |
| `fipi/client.py` | HTTP-запросы к банку, коды проектов и типов ответа, TLS |
| `fipi/parser.py` | Разбор страниц `index.php` (темы) и `questions.php` (задачи) |
| `fipi/mathml.py` | MathML → LaTeX |
| `text.py` | Текст для преподавателя |
| `material.py` | Переход к общему контракту `Material` |

Банк отвечает на `POST questions.php` с полями `search=1`, `proj`, `theme` (коды через запятую),
`qkind`, `pagesize` (до 50) и `page` (с нуля). Страницы в кодировке windows-1251. Общее число
задач передаётся в `setQCount(N)`.

Сервер ФИПИ не отдаёт промежуточный сертификат GlobalSign, поэтому Python без него не может
проверить TLS. Сертификат лежит рядом с клиентом (`globalsign-gcc-r3-dv-tls-ca-2020.pem`) и
добавляется к стандартным корневым сертификатам. Проверка TLS не отключается.

Клиент делает запросы последовательно, с паузой 0,5 с, и кеширует список тем. Банк — публичный
государственный ресурс. Не нужно выкачивать его целиком или класть задачи в репозиторий: в тестах
используются синтетические страницы с той же разметкой.

## Ограничения и дальнейшие шаги

- Разметка банка может поменяться. Тогда парсер выдаст `ParseError` с номером задачи.
- MathML переводится в LaTeX для частых конструкций. Редкие формулы могут потребовать доработки.
- Нет кеша задач между запусками. Он понадобится вместе с историей выдачи в `db/`.
- Сборка `.tex` и PDF с рисунками — следующий этап.
