# Сборка LaTeX и PDF

Обычный программный модуль, а не дополнительный агент.

1. Принимает проверенные структурированные материалы от оркестратора.
2. Подставляет их в шаблоны из templates/, экранируя обычный текст и отдельно обрабатывая формулы.
3. Собирает .tex и компилирует PDF выбранным LaTeX-движком.
4. Возвращает путь к готовому документу либо ошибку сборки. После ошибки бот не сообщает, что документ готов.

Теория, задания и ДЗ выдаются в PDF. Ответы и решения для преподавателя оформляются отдельным документом, чтобы не включать их в ученическую версию.

Для каждой подготовки и версии используются отдельные рабочие файлы в output/. После правок документ собирается заново. output/ исключена из Git и создаётся при работе приложения.

Компиляция должна иметь ограничение времени и отключённый shell escape. Промежуточные файлы и ошибки компиляции не считаются предметной проверкой физики.

Статус: каркас. Генератор и компиляция пока не реализованы.
