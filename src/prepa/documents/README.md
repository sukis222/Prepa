# LaTeX и PDF

`source.SourceDocuments.worksheet(TaskWorksheet)` — основной путь дословных
исходных задач: текст, проверенные PNG, источник и страница, клетчатое поле.
Рендерер не генерирует условия, не вызывает модель и не принимает LessonPackage.
Изображения валидируются Pillow, метаданные удаляются.

Остальные API ниже сохранены для прежнего сценария и автономных проверок.

`latex.LatexDocuments` собирает проверенные материалы в PDF через XeLaTeX или
Tectonic. Это обычный программный модуль, а не дополнительный агент.

- `tasks(StudentLesson)` — один PDF только с темой и условиями задач, текущий сценарий.
- `teacher(LessonPackage)` — ответы и решения преподавателю.
- `student(StudentLesson)` — теория с разобранными примерами, условия практики
  и собственное ДЗ без ответов; вход создаётся через `package.for_student(id)`.
- Статические шаблоны, экранирование текста, ограниченная математика,
  отключение shell escape, таймаут и отдельный каталог на каждую попытку.

Деморежим также выдаёт один PDF: `tasks(lesson, demo=True)`, с пометкой ДЕМО
в имени и документе. Под каждой задачей есть клетчатое поле 7 см с клеткой 5 мм; заголовок
и плашка блока оформлены зелёным акцентом.
`DemoDocuments` сохранён для старых автономных проверок.
`JsonDocuments` оставлен для автономной диагностики.

Зависимости, API, ограничения и проверки: [документация PDF](../../../docs/documents.md).
