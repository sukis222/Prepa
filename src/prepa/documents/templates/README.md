# Шаблоны документов

Здесь будут общие LaTeX-шаблоны оформления: материал на урок, домашнее задание и отдельные ответы для преподавателя. Шаблоны поддерживают русский текст, физические формулы и рисунки.

Шаблоны задают оформление; агенты возвращают содержание по согласованному формату. Реальные шаблоны .tex добавляются вместе с первым рабочим примером сборки.
