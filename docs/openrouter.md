# OpenRouter: отбор существующих задач

В `PREPARATION_MODE=real` бот использует `SourceSelectionBackend`: один вызов
модели выбирает ID из проверенного набора. Код копирует условия, формулы и имеющиеся
исходные изображения в неизменяемый `TaskWorksheet`. Новые условия, решения и рисунки
не генерируются. `SourceDocuments.worksheet` составляет один PDF с местом для решения.

## Настройки

В локальном `.env`, не в Git и не в чате:

```dotenv
PREPARATION_MODE=real
SOURCE_PROVIDER=reshai
# Only for explicit offline/local source mode:
# SOURCE_PROVIDER=local
# SOURCE_CORPUS_PATH=/absolute/path/to/verified-source-tasks.json
OPENROUTER_API_KEY=your_key
OPENROUTER_MODEL=dots-studio/dots-3-note-preview:free
OPENROUTER_TIMEOUT_SECONDS=120
OPENROUTER_MAX_TOKENS=4096
OPENROUTER_REASONING=off
```

Работать должен один polling-процесс на токен. Команды запуска — в README.
При запуске в контейнере путь `SOURCE_CORPUS_PATH` должен существовать внутри него:
подключите набор и его изображения доступным только для чтения томом.

Набор содержит `rights`, `llm_use_permitted: true`, `tasks`. У задачи нужны `id`,
`statement_exact`, `statement_math_exact`, `statement_sha256` (SHA-256 UTF-8 текста),
`source_url`, `page`, `exam`, `topic`, `tags`, опционально `images`/`imagespaths`.
Картинки — проверенные локальные файлы внутри каталога набора либо встроенные
`SourceImage`. Для `requires_figure: true` без изображения задача исключается.
Наличие файла в интернете само по себе не означает право его копировать и
отправлять провайдеру модели; разрешение проверяется при подготовке набора.

Локальный пример набора (только `SOURCE_PROVIDER=local`) — ранее созданные и исправленные авторские задачи
Prepa: четыре по термодинамике (два цикла и два процесса) и два примера по движению.
Это не оригинальные задачи ФИПИ и не четыре задачи сложности второй части ЕГЭ.
Набор не расширяется автоматически. Если просят 15, а подходящих задач четыре,
бот сообщает доступное число до любого запроса модели; изменить число можно через
`/edit`. Неподдерживаемая тема также не заменяется вымышленными условиями.

## Пределы и проверка

Клиент разрешает только явные ID `:free`, сверяет нулевые цены в каталоге и
передаёт `provider.max_price` с нулём для входа и выхода. Автоматических сетевых
повторов и платного fallback нет. У модели должны поддерживаться `response_format`
и `structured_outputs`. В режиме `off` каталог должен разрешать отключение reasoning;
`default` оставляет решение провайдеру.

HTTP-таймаут по умолчанию — 120 секунд, допустимый диапазон — 1–120. Отбор имеет
собственный предел 120 секунд. Для «Решай Онлайн» перед поиском модель разбирает
смысл свободного запроса: до 35 секунд на план. Общий backend-предел — 220 секунд
с разбором запроса, 170 без него; получение решений входит в этот бюджет.
При недостатке задач план корректируется один раз и поиск расширяется.
Worker ограничен 270 секундами, включая PDF. Аренда задания — 300 секунд.
Точные [промпты, параметры и ограничения](query-interpretation.md).
Лимит ответа 256–16384 токенов,
по умолчанию 8192. Обрезанный ответ не принимается; безопасное поле
`LLMError.finish_reason` отличает `length`, `content_filter` и другие причины.

Модель получает экзамен, темы, пожелания, план поиска, число и существующие условия с ID; имена,
профили и идентификаторы учеников не отправляются. Изображения сохраняются в
снимке, но модели как vision-вход не передаются. Она возвращает только ID;
неизвестный/повторный ID, лишний текст, неверное число или непокрытая тема отменяют
выдачу. Проверяются хеши исходного текста, снимка текста с математикой и изображений.
Снимок и PDF сохраняются до отправки; `/result` выдаёт сохранённые байты повторно.

Модули `RealBackend`, Theory/Assignments/Reviewer и `LessonPackage` сохранены для
совместимости и автономных тестов. Этот старый путь генерации больше не выбирается
приложением для `real`. `demo` остаётся явно отмеченным тестом интеграции.

проводятся отдельно на материалах с разрешённым использованием; один прогон
не устанавливает оптимальную модель.


## Живой источник «Решай Онлайн»

`SOURCE_PROVIDER=reshai` (по умолчанию) читает тематический каталог физики ЕГЭ на https://reshai.online. Поддерживаются 14 основных разделов. До 12 страниц каталога для обычной темы (16 для циклов) и 70 полных исходных условий на запрос; параллельно не более трёх HTTP-запросов, интервал 0,12 с, общий срок источника 35 с. Публичные ответы кэшируются на 24 часа в `output/source-cache/reshai`, SHA проверяется перед использованием.

Листинг служит только поиску. Условие берётся из блока оригинала на странице задания, рисунки — из оригинальных файлов. MathML преобразуется в математическую запись, GIF/PNG/JPEG — в проверенный PNG; прозрачность компонуется на белом фоне. Содержательные таблицы пока исключаются, чтобы не терять строки и колонки. Ответы и решения сайта не включаются. Модель выбирает только идентификаторы; код переносит текст, формулы, рисунки и ссылку. Для циклов применяется фильтр по полному исходному условию, для второй части — по признаку развёрнутого решения или текущему номеру 24. Обрезанное превью не служит доказательством отсутствия цикла. Количество совпадений проверяется после загрузки полных условий и удаления дубликатов. Если задач недостаточно, подготовка завершается отказом без генерации и без подмены локальными задачами. Поддержка ОГЭ у этого источника пока отсутствует.

Для автономных тестов можно явно выбрать `SOURCE_PROVIDER=local` и `SOURCE_CORPUS_PATH`. Это отдельный режим, автоматического перехода на него нет. Условия использования источника: https://reshai.online/soglashenie; ссылка на каждое исходное задание сохраняется в PDF.
