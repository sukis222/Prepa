# Суммаризатор занятия

`prepa.agents.summarizer.LessonSummarizerAgent` получает общий `StructuredLLM`
через зависимость. HTTP, ключи, стоимость и выбор модели остаются в `llm/`.
Он возвращает предложения для базы знаний ученика, а не изменяет прогресс сам.

## Вход и результат

Контракты находятся в `schemas/lesson_summary.py`:

- `LessonSummaryInput`: preparation_id, version, student_id, список условий
  `LessonTaskReference(task_id, statement)` и реплик
  `TranscriptTurn(turn_id, speaker, text)`.
- `LessonSummary`: те же идентификаторы и SHA-256 входа, краткий итог,
  наблюдения, следующие шаги, признаки недостатка свидетельств и неопределённости.
- Каждое наблюдение содержит тему, `understood` / `difficulty` / `unclear`,
  описание, известные ID задач и точные цитаты с ID реплик.
- Каждая рекомендация содержит ссылки на реплики, объясняющие её основание.
- `requires_teacher_confirmation` всегда `true`.

Перед вызовом сервер проверяет доступ преподавателя к ученику и занятию.
Транскрипт заранее обезличивается: имена, контакты, ссылки Zoom и прочие
личные данные не нужны модели. Один вход — один ученик; групповой транскрипт
нельзя без проверки автоматически приписывать каждому участнику.

Пример вызова после проверки доступа:

```python
from prepa.agents.summarizer import LessonSummarizerAgent
from prepa.schemas.lesson_summary import LessonSummaryInput

context = LessonSummaryInput.model_validate(payload)
proposal = await LessonSummarizerAgent(llm).summarize(context)
```

Условия ограничены суммарно 100 000 символов, транскрипт — 100 000 символов,
до 1000 реплик, до 50 задач. Длинные занятия требуют отдельной сегментации,
которая пока не реализована. По умолчанию таймаут 120 секунд.

## Граница достоверности

Код отвергает несовпавшие идентификаторы, устаревший SHA входа, неизвестные
задачи и реплики, отсутствующие дословные цитаты. Освоение и затруднение требуют хотя бы
одной цитаты ученика, объяснения только преподавателя недостаточно.
Промпт дополнительно требует самостоятельного рассуждения, а не простого
«понятно». Точная цитата не доказывает правильную интерпретацию: противоречия,
ошибки распознавания речи и оценку физического смысла проверяет преподаватель.

Предложения и подтверждённые заметки хранятся отдельно. Перед подтверждением
нужно заново проверить принадлежность занятия и SHA входа; подтверждение
другой версии не должно применяться. В пользовательскую базу попадают только
проверенные преподавателем наблюдения и согласованные рекомендации.

## Что проверено и что ещё не подключено

22 автономных теста проверяют JSON round-trip, неизменяемость, идентичность,
цитаты, ID задач/реплик, недостаток данных, лимиты ответа/входа и таймаут.
Тесты используют синтетический урок про работу газа. Это проверка контракта,
а не качества реальной модели и не точности распознавания Zoom.

Модуль готов к вызову из серверного сценария. Сам по себе он не скачивает
записи Zoom, не распознаёт аудио, не принимает файлы Telegram, не пишет в БД
и не меняет уровень ученика. Автоматического импорта Zoom пока нет.
Проведён отдельный живой smoke-test на трёх синтетических репликах про работу
и теплоту: Dots — 9,88 с, Nemotron VL — 3,19 с. Обе модели вернули
валидный результат с дословными цитатами, `unclear` и `insufficient_evidence=true`,
не объявили тему освоенной. Nemotron предложила повторение различия работы и
теплоты, Dots не предложила следующих шагов. Параметры: temperature 0.2,
4096 токенов, reasoning off, таймаут 120 с, только бесплатные модели.
Это один короткий пример, он не доказывает качество на реальных занятиях.
Отчёт без реальных данных: `output/summarizer-live-report.json` (не коммитится).

## Подключение к Telegram и PostgreSQL

В рабочем `real` режиме подключены `/summarize N`, загрузка TXT/SRT/VTT или вставка текста, предварительный итог, `/confirm_summary` и `/knowledge N`. N занятия совпадает с `/history`, N ученика — с `/students`. Миграция 004 создаёт `lesson_summary_sessions` и `lesson_summaries`. Перед чтением/записью сервер проверяет преподавателя, ученика, версию занятия и исходные задачи. Подтверждённые записи неизменяемы; повтор подтверждения идемпотентен. Полный транскрипт не сохраняется. Входные файлы — данные: команды внутри них не выполняются.

Автоматической синхронизации Zoom, аудиораспознавания и автоматического применения заметок к следующему подбору задач нет. Сводки доступны преподавателю как история знаний; профиль и уровень не переписываются.
