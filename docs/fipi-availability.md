# ФИПИ: доступность и официальный резервный источник

23 октября 2026 источник недоступности подтверждён на официальных страницах
[ЕГЭ](https://fipi.ru/ege/otkrytyy-bank-zadaniy-ege) и
[ОГЭ](https://fipi.ru/oge/otkrytyy-bank-zadaniy-oge): профилактика с 22 по 27 октября
2026 включительно. Банк заданий в этот период недоступен. DNS с локальной машины
разрешается корректно, только IPv4; отсутствие ответа TCP не связано с JSON/парсером
нашего приложения. TLS-проверка не отключалась, прокси и обходы блокировок не нужны.

## Что работает во время профилактики

`FipiMaterials` читает актуальное объявление главного сайта. При активной профилактике
сразу выбирает официальный резервный источник, не ожидая таймаута банка. При сетевой
ошибке банка также пробует его. Если объявление прочитать не удалось, обычный банк
всё равно проверяется. Неактивное прошлое объявление само по себе не включает резерв.

Резерв — **настоящий теоретический навигатор самостоятельной подготовки ФИПИ-2026**,
а не наша синтетическая заглушка и не копия полного банка:

- [ЕГЭ: механика, страница PDF 1](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/2026/fi-1-mehanika.pdf#page=1).
- [ОГЭ: механические явления, страница PDF 2](https://doc.fipi.ru/navigator-podgotovki/navigator-oge/fi-9_1_mehanicheskie_javlenija.pdf#page=2).
- [ЕГЭ: молекулярная физика, страницы PDF 1–2](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/2026/fi-2-molekuljarnaja-fizika.pdf#page=1):
  модель идеального газа, внутренняя энергия, изопроцессы, работа и первый закон,
  циклы и КПД тепловых машин.

Эти PDF живьём загружены по HTTPS с этой машины. `OfficialNavigatorMaterials`
скачивает их при запросе, сверяет SHA-256 проверенной версии, извлекает нужную
страницу через pypdf и проверяет заголовок раздела. Формулы PDF при автоматическом
извлечении теряют порядок символов, поэтому используется проверенная расшифровка
уравнений именно из этих версий PDF, явно подписанная в `Material.content`.
При изменении файла, превышении размера, перенаправлении, ответе HTML или ошибке
парсинга выдача отменяется. Новая версия источника требует проверки и обновления SHA.
Скачанные PDF, секреты и данные учеников в репозиторий не сохраняются.

## Точная тема первого рабочего сценария

Введите **«Равномерное прямолинейное движение»** либо «Равномерное движение».
Поддерживаются также точные коды **ЕГЭ 1.1.5** и **ОГЭ 1.3**. Их соответствие
проверено по официальным кодификаторам 2026, ссылка на архивы дана на странице
[демоверсий ЕГЭ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory) и
[демоверсий ОГЭ](https://fipi.ru/oge/demoversii-specifikacii-kodifikatory).

Для ЕГЭ также поддерживается тема **«Термодинамика, 2 часть ЕГЭ, циклы»** и
запросы об изопроцессах, цикле Карно и тепловых машинах. Модель получает два
проверенных фрагмента страниц 1–2 молекулярной физики. Один PDF загружается один
раз на подготовку. Готовых рисунков задач источник этому пути не предоставляет:
авторская задача должна полностью задавать координаты, оси, единицы и маршрут.

Это намеренно узкий резервный путь: произвольную кинематику, равноускоренное движение,
движение по окружности, электродинамику и другие темы он не объявляет обеспеченными
этими фрагментами. При неподдерживаемой теме возвращается `InsufficientMaterialsError`.
Для них следует дождаться восстановления банка или отдельно подключить проверенные
релевантные источники.

Модель получает реальную формулу и точный источник, затем создаёт и проверяет
**авторские адаптации**, а не выдаёт собственные примеры за дословные задачи ФИПИ.
Поиск готовых задач по всему банку во время профилактики не обещается.
Преподаватель проверяет правильность ответа и пригодность материалов для ученика.

## Проверки

`tests/test_fipi_official.py` автономно проверяет объявления, даты, узкие темы,
исходные URL и страницы, отсутствие авторизации в запросах к PDF, проверку версии,
лимит скачивания и отказ при подмене документа. Живое получение источников проверяется
отдельно; тесты с MockTransport не доказывают доступность сайта.

Реальное получение проверенного `Material` — только этап подготовки. Успешный вызов
источника не доказывает завершение генерации, независимой проверки и компиляции PDF.
