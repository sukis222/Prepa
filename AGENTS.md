# Работа над Prepa

Начните с [README.md](README.md), затем прочитайте [API и интеграцию](docs/content-agents.md)
и [критерии качества](docs/content-quality.md). Описания будущих модулей не означают,
что бот, поиск, OpenRouter, PostgreSQL или PDF уже работают.

## Общие правила

- Общий список задач находится в README.md. Задачи не закреплены за людьми;
  персональное распределение добавляется только после согласования с руководителем.
- `schemas/` — общий контракт. Перед его изменением проверьте потребителей,
  примеры, round-trip JSON и инструкции интеграции. Не дублируйте модели в своих модулях.

## Контракты и поведение

- Агенты получают `StructuredLLM` через зависимость. Ключи, HTTP, выбор модели,
  обработка ошибок провайдера и токеновые лимиты остаются в общем адаптере `llm/`.
- До подтверждения тем вызовы генерации запрещены. Профили и найденные материалы
  передаются в `GenerationContext` после серверной проверки доступа.
- Все части подготовки имеют общие `preparation_id` и `version`. Не меняйте их
  внутри агента. Контракты неизменяемы; для внешних данных используйте
  `model_validate` / `model_validate_json`. `model_copy(update=...)` не валидирует.
- После изменения содержания или контекста выполните проверку заново. Старый
  `ReviewResult` связан с точным содержимым и контекстом контрольными суммами.
- Повторы и лимит исправлений задаёт оркестратор. `ContentValidationError`
  сохраняет `content` и `feedback` для исправления; отказ из-за недостатка
  источников возвращается как `InsufficientMaterialsError`.
- Для ученического PDF используйте `LessonPackage.for_student(student_id)`.
  Не передавайте внутренний комплект или исходные `Material.content` напрямую
  в ученический шаблон. Разобранные примеры теории намеренно содержат решения.
- Обычный текст и LaTeX-математика разделены. Модуль документов обязан экранировать
  текст и безопасно компилировать формулы; prompts не заменяют эту границу.

## Проверки перед PR

После установки `python -m pip install -e '.[dev]'`:

```bash
pytest --cov=prepa --cov-branch --cov-fail-under=95
ruff check .
ruff format --check .
mypy
python examples/content_agents.py
python -m build
```

Тесты автономны: не подключайте платные модели, Telegram и базу к обычному pytest.
Демо — записанные ответы, оно не оценивает физику реальной LLM. Предметные проверки
проводятся отдельно по `docs/content-quality.md` и утверждаются преподавателем.
Не коммитьте `.env`, ключи, реальные данные учеников, PDF или `output/`.
В PR опишите поведение, изменения контрактов, проверки и интеграционные ограничения.
