# Подборщик занятия

Работай целиком локально. Для занятий используй каталог `knowledge/README.md` и готовые TeX из `output/topics/` и `output/fipi-physics/`. Внешний поиск и открытие ссылок не нужны и не допускаются.

1. Определи из запроса темы или номера заданий ЕГЭ, количество задач и ограничения. По теме открой верхний уровень каталога, затем подходящую ветку. Сопоставь формулировку пользователя с названием и кодом темы. При необходимости просмотри условия карточек в соседней ветке и выбери точные совпадения. Каждую явно запрошенную отдельную тему оформи отдельным занятием.
2. Используй `lesson-catalog` для просмотра и `compose-lesson` для сборки. Передавай найденные коды через `--topic` или номера через `--exam-number`. По умолчанию бери 20 уникальных задач. Для узкой темы выбери подходящие карточки по `--task-id` и сообщи, если их меньше. Команды описаны в [TECHNICAL.md](../../../TECHNICAL.md#подборщик-занятия-из-локального-банка).
3. В начале общего `student.tex` добавь ссылку на Умскул из строки темы в `knowledge/README.md`. Доверяй соответствию по названию темы и не открывай ссылку. Если подходящей ссылки нет, пропусти теорию. К локальному учебнику обращайся по отдельному запросу.
4. Выдай `student.tex` и `tutor.tex` с одним набором и нумерацией. Условия, рисунки и решения переноси целыми блоками. Для контрольной сборки и просмотра используй `tmp/` и рецепт проекта. В ответе укажи количество задач. При запросе PDF, в том числе для Telegram, выдавай версию с решениями по умолчанию. Ученическую версию PDF готовь, если пользователь просит её или прямо просит файл без решений.
